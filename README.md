# Minhas Finanças

App de controle de gastos pessoais (PWA): lançar falando ou pela foto do comprovante, previsão do mês, Mentor, casal, avisos de contas e backup criptografado.

- Site: https://guilherme3co.github.io/financeiro
- Manual de uso e de manutenção: [MANUAL.md](MANUAL.md)
- Código-fonte organizado: `src/` → `python3 build.py` gera o `index.html`
- Servidor (Supabase): `supabase/schema.sql`
